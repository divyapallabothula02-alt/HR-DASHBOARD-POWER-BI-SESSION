# HR-DASHBOARD-POWER-BI-SESSION
To present my dashboards to others

This repository contains a Power BI HR Analytics Dashboard built from an employee dataset. The dashboard transforms raw workforce data into actionable insights, helping HR professionals and management monitor key metrics such as headcount, diversity, and compensation structures.
________________________________________
📊 Project Overview
The goal of this project is to provide a comprehensive view of the organization's human capital. By centralizing data from departments like Engineering, IT, Sales, and Finance, the dashboard enables data-driven decisions regarding hiring trends, pay equity, and organizational growth.
________________________________________
🔑 Key Features & KPIs
Demographics Overview: Visualizes the workforce distribution by Gender, Ethnicity, and Age, promoting transparency in DEI (Diversity, Equity, and Inclusion) initiatives.
Organizational Breakdown: Analyzes headcount and role distribution across different Business Units and Departments.
Compensation Analysis: Insights into Annual Salary and Bonus percentages to identify top performers and ensure competitive pay structures.
Tenure & Hiring Trends: Tracks employee growth over time using Hire Dates to understand company scaling and retention.
________________________________________
🛠️ Tech Stack
Data Source: Excel / CSV (Employee ID, Job Title, Department, etc.)
Tool: Power BI Desktop
Data Modeling: Power Query (M) for data cleaning and DAX for custom measures.
________________________________________
📈 Business Impact
This dashboard allows stakeholders to quickly identify which departments are growing fastest, where compensation gaps may exist, and how the company’s demographic makeup is evolving over time.
